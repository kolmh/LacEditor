## 真实 UI 检查

- 编码解码窗口保持非模态，打开预览后仍可操作正文。
- 原文和结果区域中的长 URL、连续文本会随面板宽度自动换行，不再出现水平滚动。
- 编辑器右键菜单的“编码与解码”入口显示与主菜单一致的 SF Symbol 图标。
- 转换结果可复制；确认替换只修改原选区，并作为单次撤销操作提交。
- 使用隔离 Bundle ID 运行 UI 验收，未污染正式应用的最近文件和偏好设置。

## 重点回归

- URL 解码区分标准 URL 与将 `+` 视为空格的表单模式。
- Base64URL 支持无填充输入；无效输入不会被静默改写。
- 未选择文本时只检测光标所在的 URL、HTML 实体和 Unicode 转义，降低普通代码被误判为
  Base64 的概率。
- 编解码仅处理选区或受限上下文，不复制或重写整份大文件。
- 转换期间继续编辑会使旧结果失效，旧预览不能覆盖新内容。
- 现有文件格式、保存、搜索替换、Markdown 预览、语法高亮、括号匹配、多窗口、标签和
  大文件保护模式均通过自动回归。

## 已知限制与后续观察

- 智能识别采用保守策略；短 Base64、语义不明确的普通文本需要从编码解码窗口手动选择操作。
- HTML 实体仅覆盖常用命名实体及数字实体，不提供完整浏览器实体数据库。
- 100 MB 文件仍属于尽力支持范围，默认进入更严格的大文件保护模式。
- 本次发布前未执行 Instruments 下的完整人工长稳流程；自动性能门禁、Release 静态分析和
  隔离 UI 检查均已通过，长时间内存曲线继续作为后续发布观察项。

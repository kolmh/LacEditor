## 实施的验收优化

- 新增统一入口 `Scripts/run-acceptance.sh`，失败即停止并返回非零状态。
- 新增文件服务集成验证，覆盖全部支持扩展、重命名保护和文件树过滤。
- 增加 4 MiB 中英文 UTF-8 文件原子保存与完整读回验证。
- 新增 4 MB 性能基线，覆盖行索引、查找、可视区高亮和 Markdown 渲染。
- 增加产物版本、最低系统、双架构、AppIcon 实际像素和网络权限静态检查。
- 构建独立 Bundle ID 的 UI 验收 App，不污染正式应用的最近文件和偏好。
- 发布 Xcode 构建使用安静输出，成功日志更易读，失败诊断仍保留。
- 新增固定 TXT、Markdown、JSON、HTML、JavaScript UI 验收夹具。
- 新增固定 ISO Latin 1 夹具，并把 Xcode Release Analyze 固化进完整验收入口。
- 新增独立 AppKit 折叠布局回归，直接测量折叠前后高度，并覆盖展开恢复、范围裁剪及
  大范围替换后的布局有效性。

## 需实体鼠标复验

- 从 Finder 分别拖入 TXT、Markdown、HTML、JSON 和 JavaScript 文件。
- 在溢出标签栏上用滚轮横向移动，确认不切换标签且两侧渐隐随位置变化。
- 把标签拖出为新窗口，再拖回原窗口。
- 收起侧边栏后持续悬停工具栏按钮，确认临时抽屉出现并在移开后消失。
- 在所有工具按钮上持续悬停至少 2 秒，确认 Tooltip 不闪退且快捷键文字正确。

这些项目需要 Finder/AppKit 原生拖动会话、原始滚轮或无按键 hover 事件；当前自动化工具
不能可靠生成对应输入，因此保留为明确人工复验项，不影响已完成用例的结论。

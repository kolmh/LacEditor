# LacEditor 0.9.0 验收报告

## 基本信息

- 验收日期：2026-08-07
- 验收对象：LacEditor `0.9.0 (9)`
- 系统：macOS 26.6，Apple Silicon
- 最低目标系统：macOS 26.0
- 架构：arm64
- 验收标准：`ACCEPTANCE_TESTS.md`

## 版本范围

- Markdown 预览改用 `cmark-gfm 0.8.0`，支持 CommonMark 与 GFM 表格、任务列表、删除线、
  自动链接和标签过滤，并保留原始 HTML 与危险协议安全边界。
- 新增异常退出恢复：未保存标签按 revision 原子保存，正常保存、放弃修改或正常退出后清理恢复副本。
- 编辑器、标签栏和侧边栏拆分为独立协调、会话缓存、拖拽、滚动和资料库组件。
- 中大型文档改用 TextKit 非连续可视区布局；实时缩放按最高 60 Hz 合并，正文和行号同步刷新。
- 代码高亮按 64 KiB 分块缓存，被取消的深位置扫描保留检查点并从中断位置继续。
- 目标平台调整为 macOS 26.0 及以上、Apple Silicon arm64。
- 侧边栏显示或隐藏快捷键调整为 `Control+Command+B`。

  过期结果写回正文。

## 真实 UI 检查

- 50 MB JSON 文件可正常打开，打开期间不会阻塞其他标签操作。
- 文件自动进入“大文件模式”，状态栏显示对应入口。
- 实时字数统计按保护策略默认暂停，性能菜单可查看并临时恢复降级功能。
- 首次打开后光标保持在文首，状态栏显示“行 1，列 1”，未跳转到文件末尾。
- 验收应用退出时未写回测试夹具，磁盘文件内容保持不变。

## 重点回归

- 保存期间继续编辑时，保存完成后文档仍保持未保存状态，不会误判或覆盖新内容。
- 新查询、继续编辑或关闭查找窗口会取消过期搜索任务，旧结果不会回写当前文档。
- 全部替换和 JSON 格式化继续作为单次撤销操作提交。
- Markdown 预览只应用最新 generation 的 HTML，并在刷新后恢复滚动比例。
- 非活动编辑器会话受 3 个、64 MB 总预算和 24 MB 单会话上限约束；当前编辑器不会被淘汰。
- 现有文件格式、快捷键、中文输入法、行号、折叠、多窗口、标签拖动和保存确认自动回归通过。

## 已知限制与后续观察

- 100 MB 文件属于尽力支持范围，默认进入更严格的保护模式，不承诺与 50 MB 文件相同的交互延迟。
- 大文件模式下临时恢复自动换行、实时高亮或 Markdown 预览会增加 CPU 与内存开销。
- 本次发布前未执行 Instruments 下“50 MB 连续编辑 10 分钟、快速滚动 60 秒、10 个标签切换
  100 次”的完整人工长稳流程；自动性能门禁、真实 50 MB UI 检查和静态分析均已通过，
  该流程保留为后续持续性能观察项。
